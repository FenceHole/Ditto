# ✅ Setup Checklist

Check off each box. Takes about 5 minutes. Costs nothing.

## ☐ 1. Get your FREE Gemini key
- ☐ Open **https://aistudio.google.com/app/apikey**
- ☐ Sign in with Google
- ☐ Click **Create API key**
- ☐ Copy the key (paste it in Notepad for a sec)

## ☐ 2. Add the key to the app
- ☐ Open the `backend` folder
- ☐ Rename `.env.simple` → `.env`
- ☐ Open `.env`, paste your key:
  ```
  GEMINI_API_KEY=your_key_here
  ```
- ☐ Save

## ☐ 3. Start the app
- ☐ Windows: double-click `START.bat`
- ☐ Mac: run `START.sh`
- ☐ Wait for **"started successfully"**

## ☐ 4. Make a listing
- ☐ Open **http://localhost:8000/docs** (or `frontend/marketplace-app.html`)
- ☐ Upload photos of your item
- ☐ Copy the finished listing
- ☐ Paste into Facebook Marketplace → Create new listing → Item for sale
- ☐ Post!

---

## Optional (later): a dedicated Facebook account
- ☐ Make a **new, separate** Facebook account just for selling (not your business one)
- ☐ Only if you want the optional auto-poster robot — see SETUP.md. It's risky and can get
  an account banned, which is why it should never be your main account.
